## Что уже работает

Программа читает CSV с частотами и амплитудами ускорения одного изделия. Она находит частоту максимального отклика, сравнивает ее с допуском и сохраняет результат в JSON.

Это первая версия. Описание задачи находится в [docs/requirements.md](docs/requirements.md).

## Файлы

- src/analyzer.py — код программы.
- configs/calibration_limits.json — частота и допуск.
- examples/measurements.csv — учебный пример данных.
- docs/requirements.md — описание задачи и ограничений.
- result.json — результат последнего успешного запуска. Этот файл не добавляется в Git.

## Среда разработки

Версия языка по заданию — Python 3.11. Запуск этой версии программы проверен на установленном Python 3.14.7. Совместимость синтаксиса с 3.11 проверена отдельно, но запуск на самом Python 3.11 пока не выполнен. На этом этапе используются только встроенные модули Python. Внешние зависимости не требуются.

## Версия КТ2

Для КТ2 используется src/main.py. Она обрабатывает проверки одной партии: проверяет данные, сглаживает частотный отклик, сравнивает частоту максимума с допуском и считает результаты PASS, FAIL и REVIEW. Первая версия src/analyzer.py сохранена для сравнения.

```bash
python3 src/main.py
python3 src/checks.py
```

Полное описание входа и ожидаемого результата — в [src/README.md](src/README.md). Учебный пример содержит три проверки: PASS на 170 Гц, FAIL на 190 Гц и REVIEW при неоднозначном максимуме. Это заранее заданные данные, а не измерения стенда.

- [report.docx](report.docx) — отчет КТ1 с аналитическим разделом КТ2.
- [docs/modeling_kt2.md](docs/modeling_kt2.md) — описание моделей, ролей, нормализации и сложности алгоритмов.
- models/bpmn.bpmn — основной процесс и подпроцесс контроля.
- models/er_logical.drawio, algo_1.drawio и algo_2.drawio — отдельные редактируемые схемы.

Архив для просмотра собирается командой `python3 tools/build_kt2_archive.py --draft`. После своих коммитов и push нужно повторить сборку без --draft. Сборщик выгружает реальный Git-лог, проверяет дни коммитов и не меняет историю. Файлы .puml в ZIP не включаются.

### Запуск первой версии

Из папки проекта:

```bash
python3 src/analyzer.py
```

Для примера программа должна найти максимум на 170 Гц. При допуске от 160 до 180 Гц включительно результат будет «Годен».

Если входные данные неверные, программа выводит ошибку. Код завершения 0 означает, что обработка закончилась, а не то, что изделие обязательно годное. При ошибке код завершения — 1. Старый result.json после ошибки может остаться, поэтому нужно смотреть вывод терминала.
