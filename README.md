## Что уже работает

Программа читает CSV с частотами и амплитудами ускорения одного изделия. Она находит частоту максимального отклика, сравнивает ее с допуском и сохраняет результат в JSON.

Это первая версия. Описание задачи находится в [docs/requirements.md](docs/requirements.md).

## Файлы

- src/analyzer.py — код программы.
- configs/calibration_limits.json — частота и допуск.
- examples/measurements.csv — учебный пример данных.
- docs/requirements.md — описание задачи и ограничений.
- result.json — результат последнего успешного запуска. Этот файл не добавляется в Git.

## Запуск

Версия языка по заданию — Python 3.11. Запуск этой версии программы проверен на установленном Python 3.14.7. Совместимость синтаксиса с 3.11 проверена отдельно, но запуск на самом Python 3.11 пока не выполнен. На этом этапе используются только встроенные модули Python. NumPy и SciPy из requirements.txt пока не нужны.

Из папки проекта:

```bash
python3 src/analyzer.py
```

Можно указать свои файлы:

```bash
python3 src/analyzer.py examples/measurements.csv configs/calibration_limits.json result.json
```

Для примера программа должна найти максимум на 170 Гц. При допуске от 160 до 180 Гц включительно результат будет «Годен».

Если входные данные неверные, программа выводит ошибку. Код завершения 0 означает, что обработка закончилась, а не то, что изделие обязательно годное. При ошибке код завершения — 1. Старый result.json после ошибки может остаться, поэтому нужно смотреть вывод терминала.

## Что пока не сделано

Данные примера придуманы для проверки программы. Амплитуда — пиковое значение основной гармоники ускорения в м/с². Напряжение возбуждения для всех частот считается одинаковым.

Сейчас проверяется только частота по учебному допуску 170 ± 10 Гц. Подключения датчика, обработки исходного сигнала и записи настроек в устройство пока нет. Частота максимума выбирается из таблицы без уточнения между точками. Она не доказывает точное значение механического резонанса.
